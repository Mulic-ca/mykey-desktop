# 1.1.0 本地发布验证

验证环境：Windows x64，.NET 8，Inno Setup 6.7.3。

## 功能与窗口

使用 `tests/MyKey.Tests.csproj`，数据库为专门生成的测试数据，不接触个人数据库。

- 旧字段结构迁移后保留记录。
- API 删除、恢复后对全部模型字段序列化比较，包含模型、地址、标签和置顶。
- 账号整卡删除、恢复后字段比较，包含账号组、联系方式、备注、标签、排序和置顶。
- 编辑时删除单个账号可恢复；永久删除生效；30 天前一秒与到期时刻的边界。
- 自定义排序持久化、导入导出包含回收站；导入读取源数据库 WAL 中已提交的数据。
- 拼音、首字母、标签筛选，以及账号搜索只显示匹配账号。
- 更新版本比较、跳过预发布、拒绝异常下载地址、长度与 SHA-256 校验、取消和失败后的残留清理。
- 实际打开 WPF 窗口检查导航、账号切换、恢复按钮、主题保存和最小窗口尺寸。
- 截图检查五套主题、深色设置、API 编辑、账号编辑和回收站。
- 30 张账号卡片、每张三个账号的测试场景中，单次账号切换约 19 毫秒，列表数据源和卡片容器引用均未改变。这是本机样本，不代表所有设备的固定耗时。

## 安装与升级

使用 `tools/smoke-release.ps1`，测试安装包使用独立 AppId，安装到项目 `Artifacts` 下的隔离目录。

- 第二次启动退出，第一次启动继续运行。
- 关闭到托盘后再次启动，恢复原窗口而不创建第二个实例。
- 安装后数据库和设置与安装前逐字节哈希相同，安装后的可执行文件与发布文件相同。
- 更新辅助程序成功安装后保留旧程序副本并重新打开响应正常的窗口。
- 模拟安装程序返回失败，验证旧程序哈希一致、恢复标记正确、恢复后的窗口可运行。
- 卸载测试安装后保留数据。

仓库和 Release 只在本地检查完成后上传。发布后的 GitHub 检查单独验证远端版本、安装包 digest 与本地产物一致。

# MYKEY

Windows 本地 API 密钥与账号管理工具，使用 WPF 原生界面。

## 安装与更新

从 [GitHub Releases](https://github.com/Mulic-ca/mykey-desktop/releases/latest) 下载 `MYKEY-Setup-1.2.0-x64.exe`。软件仅供个人使用。

已安装旧版本的用户，直接运行新版安装包覆盖安装，无需卸载。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\MYKEY`。数据库和设置位于安装目录的 `data` 文件夹，安装包不包含个人数据，卸载保留此目录。

从 1.1.0 起，在「设置 → 常规 → 检查更新」查看正式发布版本和更新说明，确认后下载、校验、备份数据库并重启安装。可关闭启动时检查更新。更新通过 GitHub Releases 获取，不需要登录 GitHub。网络错误、下载中断或校验失败均不会替换当前程序；安装失败时更新辅助程序尝试恢复之前的可执行文件。

## 功能

- API 卡片：多个 Base URL、多把 Key（每把可填写最多 6 个字的备注）、兼容类型、自动检测与手动模型、默认模型、复制和官网跳转。默认 Key 用于模型检测和配置复制，每把 Key 也可单独复制。
- 卡片上的「刷新模型」使用默认地址和默认 Key 更新检测列表；失败保留原列表，错误提示为中文，手动模型和默认模型设置保留。
- 账号卡片：同站点多个账号、邮箱与手机列表、可选择复制的特殊备注。成功保存的邮箱、手机号会记入本地填写历史；下次输入时在输入框下方筛选候选，支持点击或键盘选择。历史随数据库导入导出。
- 中文、拼音和首字母搜索，账号搜索只保留匹配的账号。
- 两个板块均支持置顶、多标签、标签筛选及拖动排序。标签在编辑页逐个增删，两列两行，最多 4 个；旧记录超过 4 个标签时保留原数据，编辑保存前需自行删减。拖动卡片右上角的六点手柄调整顺序；置顶区与普通区分别排序。拖动前清除搜索及标签筛选，选择「自定义排序」。也可选择最新添加或名称排序。
- 回收站支持整卡恢复；编辑账号组时移除的单个账号同样可以恢复。每次删除保留 30 天，到期在软件运行时自动清理，退出期间不会有后台清理任务。
- 经典、深色、青竹、晴蓝、玫瑰五套配色，保留相同布局和控件风格。
- 单实例、启动到托盘、关闭到托盘、数据库导入导出。

## 数据库加密与备份

- 从 1.2.0 起，首次打开旧数据库时会先生成加密备份，验证转换成功后再替换工作库。SQLCipher 加密整个库，密钥由当前 Windows 用户保护，日常启动无需输入密码。旧版不能打开已加密的库；升级前请先在旧版导出一份备份，妥善保管。
- 换机或重装 Windows 前，从「设置 → 数据库 → 导出加密备份」另存一份，并保管好备份密码。在新环境选择「导入数据库」并输入该密码。仅复制 `mykey.db` 或本机自动备份不能用于换机；程序不会保存或找回备份密码。
- 可以导入旧明文备份，但程序不会改写来源文件，也不会加密或删除历史上的明文副本。旧版升级前的导出备份也可能是明文，请在确认新备份可恢复后自行处理。
- 加密保护磁盘上的库，不防止同一 Windows 账户下的恶意程序、屏幕查看或剪贴板读取，也不会擦除此前留在磁盘上的明文痕迹。

## 源码与第三方许可

程序入口及托盘在 `src/App/`，界面在 `src/Views/`，数据库在 `src/Data/`，模型及搜索在 `src/Core/`，更新及模型检测在 `src/Services/`，测试在 `tests/`。数据库依赖的第三方许可见 [`licenses/`](licenses/)，安装后也可在 `licenses` 文件夹中查看。
